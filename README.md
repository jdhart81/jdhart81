# Justin Hart

I build open tools for understanding mathematical statements, inspecting research evidence, and running auditable agent services.

**Start with [ProofLens](https://jdhart81.github.io/prooflens/): explore a mathematical statement, change an input, and see how its assumptions shape the result.**

## Try one real question

ProofLens is the easiest place to begin. Load a built-in example, change one parameter, and describe what changed and why. Then try a supported statement you want to understand.

If it helps you answer a real question, or you get stuck, [share a short first-use report](https://github.com/jdhart81/prooflens/issues/new?template=builder_trial.yml). A successful example or a precise failure gives us something concrete to improve.

## How I build

- Make results inspectable: source, assumptions, and provenance should be easy to find.
- Keep evidence distinct: a numerical preview is not a proof; a successful build is not research certification or empirical validation.
- Credit contributors and upstream work, and turn useful feedback into clearer examples and fixes.

ProofLens source previews do not run Lean. Canon certification applies only to exact reviewed claim scopes; its historical sources remain separately labeled. Fleet's public agent cores are distinct from its hosted operations.

Bug reports, reproduction notes, documentation improvements, and bounded contributions are welcome. Follow each repository's contribution and security guidance.
