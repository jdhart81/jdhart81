# Conservation first use

See how GSIP, VergeCommon and DFM could support one practical conservation workflow with farmOS activity records and OpenTEAM data-rights vocabulary.

[Open the visual showcase](https://jdhart81.github.io/jdhart81/conservation-first-use/SHOWCASE.html) · [Step-by-step walkthrough](START_HERE.md) · [Builder handoff](BUILDER_HANDOFF.md) · [Local validation](VALIDATION.md)

All records are fictional. The DFM–VergeCommon Landscape Package contract exists. GSIP/farmOS adapters are proposed; no end-to-end automatic integration, partnership or ecological outcome is claimed.

Download this directory to run the offline example. Use Node 22 or newer, install the upstream locked dependencies as documented in START_HERE, then run `node run-demo.mjs`.
